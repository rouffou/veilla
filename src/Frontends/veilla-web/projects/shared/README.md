# @veilla/shared

Bibliothèque partagée par les trois applications du workspace `veilla-web` : configuration d'exécution, authentification OIDC, internationalisation, coquille accessible et composants communs. Voir le [README du workspace](../../README.md).

Consommée directement depuis les sources via l'alias TypeScript `@veilla/shared` (et `@veilla/shared/testing` pour les tests) ; `ng build shared` produit un paquet Angular si besoin.
